# Tarrant Resources

Project-specific FiveM resources belong under this namespace.

Use this area for future custom Tarrant RP systems such as economy, jobs, businesses, housing, government identity, and commercial integrations. Do not modify framework or vendor resources directly for project-specific behavior.

This directory is documentation-only until a child resource with an `fxmanifest.lua` is added. Do not add `ensure [tarrant]` to `server.cfg` before then; FXServer cannot start an empty resource category.
